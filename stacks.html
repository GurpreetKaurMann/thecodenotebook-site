In simple words

A stack is Last In, First Out. Three operations — push, pop, peek — and all three are O(1).

In Java use ArrayDeque, not the old Stack class. Stack extends Vector, so every method is synchronized and slower; it is kept only for old code.

Think of it like…
A pile of plates. You add to the top and you take from the top. The plate at the bottom comes out last.

Key ideas

  • Matching pairs: for every opening bracket push the closing one you expect. On a closing bracket, pop and compare. At the end the stack must be empty.
  • Monotonic stack: keep indexes; while the new number is bigger than the top, pop it — you have just found its next greater element. Every index is pushed and popped once, so it is O(n).
  • Min stack in O(1): store a pair {value, minimum below it} instead of a single number, then getMin is just peek.
  • Evaluate expressions: push numbers; on an operator pop two, apply, push the result. Careful with minus and divide — the second pop is the left operand.
  • Recursion is a stack. Every call is pushed on the call stack, so any recursion can be rewritten with your own stack to avoid StackOverflowError on deep structures.

Operations & cost

OperationCost
push / pop / peekO(1)
search insideO(n)
isEmpty / sizeO(1)

Java code

// Valid Parentheses — LeetCode 20
boolean isValid(String s) {
    Deque<Character> st = new ArrayDeque<>();
    for (char c : s.toCharArray()) {
        if (c == '(') st.push(')');
        else if (c == '[') st.push(']');
        else if (c == '{') st.push('}');
        else if (st.isEmpty() || st.pop() != c) return false;
    }
    return st.isEmpty();            // leftover open brackets = false
}

// Next Greater Element — LeetCode 496 (monotonic stack)
int[] nextGreater(int[] nums) {
    int n = nums.length;
    int[] res = new int[n];
    Arrays.fill(res, -1);
    Deque<Integer> st = new ArrayDeque<>();      // indexes
    for (int i = 0; i < n; i++) {
        while (!st.isEmpty() && nums[st.peek()] < nums[i])
            res[st.pop()] = nums[i];             // found it
        st.push(i);
    }
    return res;      // [2,1,2,4,3] -> [4, 2, 4, -1, -1]
}

Interview traps to remember

  • Printing: with ArrayDeque, pushing 1, 2, 3 prints [3, 2, 1] (top first). The old Stack class prints [1, 2, 3] (bottom first). Same pushes, opposite output.
  • Use ArrayDeque: Stack extends Vector, so every method is synchronized and slower. It is kept only for old code.
  • No nulls: ArrayDeque throws a NullPointerException on push(null) — which is why pollFirst() returning null always means empty.
  • Empty stack: pop() on an empty ArrayDeque throws NoSuchElementException. Check isEmpty() first, or use pollFirst(), which returns null instead.
  • Valid Parentheses: two traps — check for an empty stack before popping, and remember that leftover open brackets mean false.
  • RPN: for minus and divide the second pop is the left operand. 2 1 + 3 * is 9.

Spot it when

  • The problem says 'nearest', 'next greater', 'next warmer' or 'previous smaller'.
  • Brackets, parsing, undo, or a back button.
  • You need the minimum or maximum so far, in O(1).
  • A recursion is too deep and throws StackOverflowError.
